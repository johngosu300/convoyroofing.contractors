PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser. Keep convoy-logo.jpeg in the same folder.

PUBLISH ONLINE (NETLIFY DROP)
1. On a computer, visit https://app.netlify.com/drop
2. Sign in or create an account if asked.
3. Extract this ZIP. Drag the convoy-roofing-website folder or its contents into the upload area.
4. Netlify will provide a public website URL.

ALTERNATIVE: GITHUB PAGES
1. Create a GitHub account and a new repository.
2. Upload index.html and convoy-logo.jpeg to the repository root.
3. Open repository Settings → Pages and enable deployment from the main branch/root.
4. Use the public URL GitHub provides after deployment.
